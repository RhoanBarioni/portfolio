# Rhoan Barioni — Portfolio

Portfolio pessoal de Rhoan Barioni, desenvolvedor Full Stack e estudante de Ciência da Computação.

## Development

Você precisa do Node.js e npm instalados.

```sh
git clone <url-do-repositorio>
cd portfolio
npm install
npm run dev
```

## Tecnologias

- TanStack Start
- TypeScript
- React
- Tailwind CSS
